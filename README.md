# GAIA 数量計算書コンバーター

数量計算書（Excel または PDF）から必要な行だけを抽出し、GAIA が読み込める
7シート形式の金抜 Excel と確認用 CSV を作成する Windows 向けツールです。

変換処理は GAIA 本体から独立しています。GAIA の起動、ファイル選択、
取込確定、歩掛り・単価選択は自動操作しません。

## 今回の設計方針

変換仕様は、GAIA で正常に読み込めることを確認済みの
`直地区　道路・下水道等災害復旧工事.xlsx` を基準にしています。

`00_level tree.pdf` や施工パッケージ資料は、通常の変換処理には使用しません。
数量計算書に明記された工種・種別を外部ツリーで上書きすると、工事固有の
階層を壊す可能性があるためです。

出力 Excel へ入れる情報は次の最小限に限定します。

- 工事名、積算年月、工種区分、単価地区
- 費目、工種、種別、細別
- 規格・条件、数量、単位
- 十分な根拠がある場合だけ GAIA コード

備考、出典、数量算出要領ページ、判定ステータス、警告は GAIA 用シートへ
書きません。これらは確認用 CSV にだけ残します。

## GAIA 取込シートの実測仕様

主な取込データは `本工事費内訳表` に4行単位で配置されます。

| 内容 | 基準行のセル | GAIA 判定文字 |
| --- | --- | --- |
| 費目 | A列 | 次行のM列に `費目行` |
| 工種 | B列 | 次行のM列に `工種行` |
| 種別 | C列 | 次行のM列に `種別行` |
| 細別グループ（ある場合） | D列 | 次行のM列に `細別行` |
| 規格グループ（ある場合） | E列 | 次行のM列に `規格行` |
| GAIA検索対象の明細 | D、E、またはF列 | 判定文字なし |
| 規格・施工条件 | 明細の次行D列 | なし |
| 数量 | 明細行のH列 | なし |
| 単位 | 明細行のJ列 | なし |
| GAIAコード | 明細行のM列 | 例: `[CB240210]` |

1ページは40行、1ページ内は4行ブロックが9個です。テンプレートは
`鏡`、`本工事費内訳表`、`内訳書`、`明細書`、`代価表`、`単価表`、
`施工パッケージ` の7シートを保持します。

詳しい解析結果は [GAIA_IMPORT_SCHEMA_JA.md](GAIA_IMPORT_SCHEMA_JA.md) を
参照してください。

## 階層の変換ルール

| 数量計算書 | GAIA |
| --- | --- |
| 費目・章・セクション | レベル1 / 費目 |
| `工種` | レベル2 / 工種 |
| `種別` | レベル3 / 種別 |
| `細別`・名称 | レベル4 / 細別 |
| `規格`・`規格等` | 細別の次行 |
| `数量` | H列 |
| `単位` | J列 |

原本に費目が無い場合は `本工事費` を使用します。原本に工種または種別が
明記されていれば、その値を最優先し、カタログで上書きしません。

6列の道路数量総括表 (`工種 / 種別 / 細目 / 単位 / 数量 / 摘要`) は例外として、
`種別` を明細名、`細目` を規格として解釈します。細目が次行へ続く場合も、
直前の明細の規格へ結合します。

原本の工種・種別が空欄のときだけ、同じ名称・単位・規格を持つ過去の
GAIA 取込実績から一意に判断できる階層を補います。一意に判断できない場合は
`工種未確認` または `種別未確認` とし、誤った階層を推測しません。

## GAIA 名称・コードの照合

`assets\gaia_import_catalog.json` は、正常取込済みの `直地区` と `宝立地区`
Excel から抽出した名称、規格、単位、階層、GAIA コードのカタログです。

変換時は明細名を正規化し、名称、単位、規格、工種、種別を組み合わせて
照合します。安全に一致した場合は、GAIA 実績と同じ明細名を出力するため、
取込後の GAIA 名称検索で一致しやすくなります。

正常取込済み実績に `細別行`、`規格行` がある場合は、そのグループも再現し、
検索対象の明細を実績と同じ D、E、F 列へ配置します。過去工事の単価・金額・
`施工 第...`・`明細 第...` は、新しい工事へコピーしません。

GAIA コードは次の条件を満たす場合だけ M列へ入れます。

- 細別名が完全一致する
- 単位が一致または安全な等価単位である
- 規格または工種・種別の文脈が十分に一致する
- 候補コードが一意である
- Excel 原本から正常に抽出された行である

PDF、OCR、複数候補、単位不一致、規格不足ではコードを確定しません。
コードが空でも、細別名、規格、数量、単位は出力されるため、GAIA 取込後に
歩掛り・単価を手動検索できます。

## 対応ファイル

### Excel

- `.xlsx` / `.xlsm`
- `工種`、`種別`、`細別`、`規格`、`単位`、`数量` の見出しから列を判定
- 見出し位置、開始行、列順が異なる表
- 結合セル、省略された上位階層、次行数量、合計行

### PDF

- 文字情報を持つ数量総括表・数量集計表
- 画像 PDF の罫線表と Windows 日本語 OCR
- `規格` 列を持つ7列表と、`細目` を規格として使う6列道路表
- 複数ページに分かれた数量総括表と表題のない継続ページ

PDF はレイアウト崩れや OCR 誤認識が起きるため、全行を原本と照合する
`SOURCE_REVIEW_REQUIRED` 扱いです。PDF から GAIA コードは自動設定しません。

未知の書式を100%安全に自動変換することはできません。表を認識できない
場合は、誤った Excel を作らずエラーで停止します。新しい様式は実例と
回帰テストを追加して対応範囲を広げます。

## Portable EXE の使い方

1. `GaiaQuantityConverter-win64.zip` を右クリックして「すべて展開」します。
2. 展開したフォルダー内の `GaiaQuantityConverter.exe` を起動します。
3. 「ファイルを選ぶ」で数量計算書を選択します。
4. 「GAIA取込Excelを作成」を押します。
5. 「確認表を開く」で原本と照合します。
6. GAIA では `_GAIA取込用.xlsx` を手動で選択します。

CSV は確認用であり、GAIA へは取り込みません。元の Excel・PDF は変更しません。
Python のインストールは不要です。Windows 10 / 11（64ビット）を対象とします。

画像 PDF を使用する PC では Windows の日本語 OCR 言語が必要です。社内試用版
EXE は未署名のため、SmartScreen 等の確認が表示される場合があります。

## 作成されるファイル

- `元ファイル名_GAIA取込用.xlsx`: GAIA で選択するファイル
- `元ファイル名_GAIA取込用_確認.csv`: 原本照合・一致根拠・警告
- `元ファイル名_GAIA取込用_抽出結果.json`: 抽出診断
- `_OCR確認資料`: PDF/OCR の確認画像（PDF の場合）

積算年月または単価適用年月を原本から取得できない場合は PC の当日を使用します。
必要に応じて GAIA で変更してください。

## 開発環境

```powershell
git clone https://github.com/jayxavierito/gaia-automation.git
cd gaia-automation
Set-ExecutionPolicy -Scope Process Bypass
.\setup.ps1
```

直接変換する例:

```powershell
.\run_converter.ps1 `
  -Source "D:\projects\数量計算書.xlsx" `
  -Location "珠洲市〇〇町地内" `
  -Output ".\outputs\project_GAIA取込用.xlsx"
```

`積算年月` を明示する場合は `-PriceDate "2026-07-01"`、
鏡シートの工種区分を明示する場合は `-WorkCategory "橋梁工事"` を追加します。

テスト:

```powershell
.\.venv\Scripts\python.exe -m unittest discover -v
```

Portable EXE の作成:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\build_portable_exe.ps1
```

出力は `dist\GaiaQuantityConverter\GaiaQuantityConverter.exe` と
`dist\GaiaQuantityConverter-win64.zip` です。単一 EXE ではなくフォルダー形式を
採用しているため、EXE だけをフォルダー外へ移動しないでください。

## GAIA カタログの更新

正常取込済みの GAIA Excel を追加してカタログを再作成できます。

```powershell
.\.venv\Scripts\python.exe .\build_gaia_catalog.py `
  "D:\approved\GAIA正常取込済み.xlsx" `
  --output ".\assets\gaia_import_catalog.json"
```

複数ファイルを指定できます。カタログには元ファイル名と内容ハッシュが記録される
ため、社外配布前に使用可否を確認してください。

## GAIA での確認

まず本番工事ではなく、使い捨てのテスト工事へ取り込んでください。

1. `珠洲市Excel`、`珠洲市`、`一般土木`、`金抜き` として認識されるか確認します。
2. 費目、工種、種別、細別、規格、数量、単位を原本と比較します。
3. GAIA が選んだ歩掛り、単価、補正条件、経費区分を確認します。
4. 代表行を手作業の積算結果と比較してから対象範囲を広げます。

GAIA 本体の UI 自動操作は、コンバーターとは分離したままにします。
